Get started with Technician Console

Windows · Visual Studio
  1. Download the source ZIP using the button above and extract its contents.
  2. Open FixFlowIT.TechnicianConsole.vbproj in Visual Studio 2022 or newer with .NET 8 support.
  3. Select Build → Rebuild Solution and then press F5 to launch.
  4. Create and manage service records across eight connected modules. Data is saved in local application storage.
The Technician Console is a Windows desktop application and runs separately from this website. Download the source project here to build and run the Windows application. The website's Fix Log and the desktop console do not currently share a database.

One connected service workflow

Register a customer and their equipment, open a support ticket, document the issue and technician findings, schedule maintenance, and track the completed repair in Repair History and Reports & Analytics. Built-in diagnostic tools support day-to-day troubleshooting.
